┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚨 IMPORTANT NOTES                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

⚠️ CERTIFICATE WARNING IS NORMAL
├─ You'll see: "Your connection isn't private"
├─ This is because certificate is self-signed
├─ Only happens in development/testing
├─ Production will use Let's Encrypt (trusted)
└─ Click "Advanced" → "Proceed to localhost"

⚠️ SERVICE WORKER REQUIRES HTTPS
├─ Won't work on HTTP
├─ Must use https://localhost:3001
├─ localhost and 127.0.0.1 are exceptions
├─ This is why we need local HTTPS
└─ Once you test, you're ready for production

⚠️ BROWSER CACHING
├─ Chrome sometimes shows old version
├─ Solution: DevTools → Settings → "Disable cache while DevTools open"
├─ Or: Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
└─ Clear site data if needed: DevTools → Application → Clear site data

⚠️ PORT 3001
├─ If already in use, change in https-server.js
├─ Find: const PORT = 3001;
├─ Change to: const PORT = 3002;
└─ Try different port if conflict

⚠️ KEEP SERVER RUNNING
├─ Server needs to run while you test
├─ Keep PowerShell window open
├─ Don't close the terminal
├─ Press Ctrl+C to stop (when done)
└─ Only stop when testing is complete


┌──────────────────────────────────────────────────────────────────────────────┐
│ 🆘 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

ISSUE: "ENOENT: no such file or directory ... key.pem"
FIX:
1. Make sure certificates exist: ls client\build\certs\
2. If missing, regenerate: mkcert localhost (in certs directory)
3. Restart server: node build/https-server.js

ISSUE: "Service Worker won't install"
FIX:
1. Make sure using HTTPS (https://localhost:3001)
2. Check DevTools Console for errors
3. Try: DevTools → Application → Clear site data
4. Refresh page and try again

ISSUE: "Can't connect to https://localhost:3001"
FIX:
1. Make sure server is running: node build/https-server.js
2. Check server is in client directory
3. Make sure not using HTTP (needs HTTPS)
4. Try different port if 3001 is in use

ISSUE: "Offline mode not working"
FIX:
1. Check Service Worker registered first
2. Make sure offline checkbox checked in Network tab
3. Refresh page AFTER checking offline
4. Try: DevTools → Application → Clear site data

ISSUE: "Installation button not appearing"
FIX:
1. Run Lighthouse audit (DevTools → Lighthouse)
2. Check for manifest warnings
3. Verify all icons present (192x192, 512x512)
4. Check manifest.json file
